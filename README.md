# Attendance Management System (AMS)

## Introduction

Welcome to the Attendance Management System (AMS) project.  
This system is designed to simplify and streamline the process of attendance tracking and management within educational institutions and organizations. It offers a comprehensive set of features tailored for students, teachers, and administrators, ensuring efficient management of attendance records.

## Features

### 1. User Authentication

**Student:**
- Access personal attendance records
- View timetables
- Mark and update attendance
- View faculty's attendance sheet
- Get consolidated reports
- Access calendar of events

**Teacher:**
- Manage class attendance
- Mark and update attendance records
- View On Duty (OD) status
- Get defaulters (students with attendance less than 75%)
- Generate reports
- Access calendar of events

**Administrator:**
- Add/remove admin accounts
- View and edit timetable
- View and edit calendar of events
- Access login logs

### 2. Timetable Management
- Dynamic scheduling of classes for students
- Real-time visibility into class schedules for effective time management

### 3. Attendance Marking and Tracking
- Students can mark and update their own attendance
- Teachers can mark and update attendance records for their classes
- View student attendance history
- Automated tracking of attendance percentages and reporting

### 4. Calendar of Events
- View and update institutional events (admin only)

### 5. Role-Based Access Control
- Differentiated access levels for students, teachers, and administrators
- Ensures data privacy and security

## Getting Started / Prerequisites

Before you begin, make sure the following are installed:

- **MySQL**  
  - Download and install MySQL  
  - Set up a MySQL database for the AMS project

- **Java to SQL Connector**  
  - Use a Java to SQL connector like JDBC  
  - Download and configure the connector for your project

- **Java Compiler**  
  - Install the Java Development Kit (JDK) if not already available

## Execution Steps

1. Clone the repository  
2. Install dependencies, including the Java to SQL connector  
3. Establish a connection between the Java program and the SQL database  
4. Configure the database settings in the project  
5. Create necessary tables in your local system  
6. Compile the Java source code using the Java compiler  
7. Run the application

## Usage

### Student
- Log in using student credentials
- View class timetable
- Mark and update attendance
- View attendance history
- View faculty's attendance records
- Access the calendar of events

### Faculty / Teacher
- Log in using faculty credentials
- Sign in to respective course (mandatory)
- View and update class attendance
- View On Duty (OD) status for students
- Identify defaulters (attendance < 75%)
- Generate attendance reports
- Access the calendar of events

### Administrator
- Log in using admin credentials
- Add or remove admin accounts
- View and edit timetable
- View and edit the calendar of events
- Access login logs for auditing purposes
